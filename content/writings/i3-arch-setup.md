I keep my desktop boring on purpose. Arch keeps the base tiny; i3 keeps windows where I put them; everything else is one keybind away and otherwise invisible.

The three binds I actually use all day: a launcher, a terminal, and a "throw this window to that workspace" motion. Everything past that is decoration I've slowly deleted.

If you're starting out, resist ricing for a week. Live with the defaults, note what annoys you, then fix exactly those things.
